PROJETO GESTÃO DE EQUIPAMENTOS DA ESCOLA - MÓDULO 10 (POO, 2.ª parte)
FASE 1 - Referências, new, null, garbage collector
A aplicação ganha: Classe Equipamento; adicionar, editar e remover na lista

Projeto inicial: os dois formulários estão desenhados e os botões já têm os eventos criados.
As pastas Modelo e Logica estão vazias: a classe Equipamento é criada por vocês (botão direito em Modelo > Adicionar > Classe).

COMO ABRIR
  Abrir o ficheiro GestaoEquipamentos.sln no Visual Studio 2022 e carregar em F5.
  O projeto usa C# 7.3 (a versão do .NET Framework 4.8). Está preparado para .NET 8;
  para usar o .NET Framework 4.8, ver o comentário no ficheiro GestaoEquipamentos.csproj.
